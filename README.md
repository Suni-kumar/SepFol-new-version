# SepFol - Data Vault & Revision Flashcards

A modern Cyber-AMOLED study and productivity application featuring a secure data vault, PDF & document viewers, 3D interactive flip revision flashcards, and a floating focus timer.

## Features

- **SepFol Data Vault**:
  - Directory structure and nested folder navigation with breadcrumb trail
  - Multi-format file storage and importing (PDFs, Images, Markdown, Code, Text)
  - In-browser PDF & Document Viewer with reading progress and bookmark persistence
  - In-browser High-Resolution Image Viewer with zoom & pan controls
  - Custom colored tags/badges and quick filter modes (All, Starred, Custom Badges)
  - Dynamic responsive grid layouts (1 to 4 columns)
  - Real-time search and multi-selection batch management
  - JSON backup and restore capabilities

- **Revision Flashcards**:
  - Deck organization with vibrant cyber color gradient themes
  - 3D interactive flip cards with active recall questions and answers
  - Card mastery tracking with celebration feedback
  - Full content reader modal and card management drawer

- **Floating Focus Study Timer**:
  - Draggable floating timer pill with real-time countdown
  - Quick presets (15m, 25m, 45m, 60m, 2h, 3h) and custom duration settings

- **Theme & Aesthetics**:
  - Cyber-AMOLED UI with frosted glassmorphic containers (`GlassBox`) and neon glowing accents
